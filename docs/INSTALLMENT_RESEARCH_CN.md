# 分批投资研究：使用与判断口径

本功能在 VerdictQuant 桌面的“股票研究”页使用。目标是判断当前价格是否已值得开始分批投入，接受合理价格和分批承担波动，不以历史最低价或站回某条均线作为必要条件。

## 日常使用

1. 打开桌面软件，先看上次保存的分析。软件打开不会联网、调用模型或推送消息。
2. 点击“更新分析”，软件才读取公开行情、SEC 财务和公告、新闻线索与供应商估值，并调用已配置的 AI。默认使用本机官方 Codex 的 ChatGPT 登录和 `gpt-5.3-codex-spark`，消耗该账号的 Codex 额度。可选择已有 API 配置，后者另行计费。界面显示实际 token 用量，不编造余额或费用。
3. 逐股查看当前判断、价格与估值、理由、风险、情景假设和下次复核条件。走势图只画实际历史收盘，不画预测底部。

2026-09-08 界面改版后，左侧为统一导航。股票研究首屏展示关键数字、研究清单、所选股票判断与真实走势图；可按代码/名称搜索，或筛选“可分批”“暂缓新增”“待核验”。完整理由在“依据与风险”，数据表在“估值与财务”，原文在“来源”，历史研究和已登记投入在“记录”。底部“研究信息与计划明细”展开后查看模型、用量、完整时间和预算缺口。

投资计划分为“预算与持仓”和“额度规则”，保存与取消始终保留在窗口底部。界面中的简称不改变原判断：正常投入仍需满足个人预算和持仓限制；需要更新、历史快照或旧模型状态会明确标记。仅查看页面、搜索、切换或调整图表范围不会联网。

研究范围为 NVDA、TSLA、SPCX、COIN、TSM、ASML、MU、CEG、VST、SNDK、SKHY。001437、VOO、QQQM 保留在核心基金与行情观察范围，不生成自动赎回或减仓指令。名单是研究范围，不是已确认持仓。

## 判断代表什么

| 显示 | 含义 |
| --- | --- |
| 可开始小额分批 | 公司层研究条件成立，且用户确认该股目前无持仓；投入规模仍受计划限制 |
| 可按正常节奏投入 | 当前价位处于所列假设的可接受估值区间，无须等到全年最低价 |
| 价格更有吸引力 | 相对所列估值情景更有余地；不代表自动加倍，更不代表收益保证 |
| 本期暂缓新增 | 经营理由或估值不满足当前条件；需要列明原因和重新评估条件，不等于卖出 |
| 本次证据不足 | 资料、身份、时间、币种或模型输出未通过校验，不能形成新判断；不等于建议中断原有计划 |

价格分位只表示当前价格在观察窗口的位置。大幅回撤不自动等于低估；创新高但盈利提升、估值合理，也可以满足分批研究条件。新上市公司使用当前发行人的独立历史，不拼接旧股票代码所代表公司的数据。

## 投资计划与本期金额

“投资计划”由用户手工填写月预算、持有年限、总投资资产市值、单股/主题上限、各股票新增资金分配比例和当前持仓市值。全部金额用 USD，其他币种资产应按用户确认汇率折算。空白是未知，不自动当零。

核心基金可填写市值，但不参与新增个股预算分配。基金没有完整穿透；已知直接持仓的主题统计不代表全组合的精确行业权重，也不代表风险已充分分散。

直接持仓共享上限的分组为：AI与半导体（NVDA、TSM、ASML、MU、SNDK、SKHY），发电与电力（CEG、VST），高不确定性成长（TSLA、SPCX、COIN）。最后一组是风险预算分组，不代表同一行业。指数及主动基金还可能重复持有这些公司，因此实际重叠可能高于目前直接持仓统计；详情页和投资计划会同时说明这些关系。

默认分批比例可在计划中修改：高风险候选单次最多使用该股本月剩余额度的25%，正常判断50%，更有吸引力100%。这些是透明的产品起始规则，不是收益最优公式，也不是全账户仓位。额度还受剩余月预算、单股与直接主题上限约束；不会自动挪用另一只股票的预算。此方案以至少三年的个股持有计划为基本适用范围，更短期限需要另行复核。

每只股票分别保留持仓确认时间。修改预算或持有年限不会刷新未改动持仓的时点；只有该股金额变化，或用户明确勾选已重新核对所有持仓，才更新相关时点。快照之后明确登记的投入会计入额度占用，避免重复建议超过上限。计算依据是手工金额快照，不能冒称与券商实时对账。

“本期已投入”只用于登记已经完成并由用户确认的投入，需二次确认。软件不会把研究建议自动记作成交，也不会连接账户或发送委托。同一事件编号重复提交不会重复计入。预算或持仓缺失时，公司层判断仍可显示，但不会猜测实际投入金额或股数。

## 来源、时间与估值限制

- 行情日期、财报期间、来源披露/抓取时间、分析生成时间分别保存。美股完成交易日使用官方日历，周末和节假日不误作漏行情。
- SEC companyfacts 保存原币种、指标标签、报告期间和披露日期。EPS 不跨拆股或 ADR 口径拼接。未找到有效季度数据就保留缺失。
- Yahoo 财务和估值是当前供应商快照，可补充部分外资公司最新季度资料，但不替代正式财报。其期末日期不代表披露日，禁止据此冒充历史时点回测证据。
- 同期同币种可比数值明显冲突时先停止该条判断；不会取更好看的数字。亏损公司的负市盈率不当作便宜，存储周期股不直接套高景气期静态 PE。
- 企业价值包含净债务。只有在市值、企业价值、币种、日期齐全时才换算股权价格，缺少输入就保持待核验。
- 公告最多读取两份、每份有限正文片段；NVDA、COIN 有已验证的官方公告备用入口。新闻列表是标题线索，不代表读完全部新闻或排除所有风险。外部正文和标题都是不可信数据，不能向模型授予执行指令的权限。
- 模型提出的合理倍数和价格区间是明确列出的情景假设，不是市场公认公允价值或未来价格承诺。模型的把握程度不是经过验证的上涨概率。

## 保存、过期与故障

默认独立目录为 `D:/CodexData/finance/monitoring/installment`；没有此金融目录的机器使用系统用户数据路径。可通过 `VERDICTQUANT_RESEARCH_ROOT` 指定其他目录。

每次分析保存独立结果和来源。历史结论不会在打开时被悄悄改写；只在显示层核验有效期并按最新用户计划计算预算。出现新完成交易日、超过48小时或更早的逐股复核期限，旧金额失效并明确标记。每只股票分别缓存有效判断：只有该股实际文本、数据或模型设置变化，或超过原复核时限，才重新分析。传输时间、脚本随机值等不触发无意义重算。缓存最多24小时，复用不能延长原判断的复核期限，也不缓存未通过验证的模型输出。

网络、模型限流、空输出、截断、错误引用或取消，不会伪造成功判断。部分公开数据仍可保留供查看，旧完整记录可在历史中回看。已经发给模型的请求可能已计费。

真实持仓、预算和投入记录只在本机计算，模型仅接收公开资料。密钥保存在现有系统安全存储，不进入普通日志、报告或源码。本功能没有真实交易、自动下单、后台定时任务或自动恢复旧监控的功能。

本机 Codex 通路不会读取、提取或复制登录 token，也不会创建 API Key。每次使用官方客户端处理公开资料，在独立临时目录中运行、只读沙箱、关闭 shell/浏览器/插件/记忆等能力，不加载用户项目配置；结束后只保留结构化分析和实际用量。登录、订阅资格和模型权限仍由官方客户端控制，失效时需要在官方 Codex 内恢复。本机需保留已安装的官方 Codex；软件不会静默改用收费 API。

## 验证入口

数据与决策测试：`python -m pytest tests/unit/test_installment_sources.py tests/unit/test_installment_documents.py tests/unit/test_installment_decision.py tests/unit/test_installment_service.py`。

桌面交互测试：在已安装 PyQt6 的解释器运行 `python -m unittest tests.unit.test_installment_gui tests.unit.test_manual_monitor`。

离线测试使用隔离反例，不调用收费模型或真实账户。真实联网与打包验证在交付回执中单独记录，不把测试通过当作投资策略已证明盈利。
